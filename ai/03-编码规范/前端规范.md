# 前端编码规范（强制）

> 技术栈：Vue 3 + `<script setup>` + Vite + TailwindCSS v3 + Ant Design Vue。违反任一条会被打回。

## 1. 组件写法

- 必须使用 `<script setup>` 组合式 API，**禁止选项式 API**（`data()/methods()` 等）
- `v-model` 一律用 `defineModel`，不要手写 `props + emit('update:modelValue')`
- Props 必须声明类型 + 默认值，用 `defineProps` / `defineEmits`

## 2. 样式（100% Tailwind）

- **禁止**原生 CSS、自定义 class、`!important`
- `style` 块仅允许用 `@apply` 抽离公共样式
- Tailwind 类名顺序固定：

```
布局定位 → 显示/弹性布局 → 宽高尺寸 → 内外边距 → 文字样式 → 背景/文字/边框颜色 → 圆角/阴影 → 交互状态(hover/focus) → 响应式(sm/md/lg)
```

## 3. 工程约定

- 有通用组件（`frontend/src/components/`）先用通用组件，**禁止重复造轮子**
- 页面模块用 `文件夹/index.vue` 写法（如 `views/users/index.vue`）
- 有关联关系的文件放同一文件夹
- 响应式移动端优先，`sm/md/lg` 正确使用

## 4. 代码风格

| 项 | 规则 |
| --- | --- |
| 引号 | 单引号 |
| 缩进 | 2 空格 |
| 分号 | 禁止 |
| 空行 | 无多余空行 |
| 命名 | 组件大驼峰；变量/方法小驼峰；常量全大写下划线 |
| 注释 | 新增逻辑必须写清晰注释（中文） |
| 结构 | 单文件组件顺序：script → template → style |

## 5. 改前端前的检查点

- 新页面：先读 [信息架构](../02-架构与权限/信息架构.md) 确认归属，再按 [新增管理台页面](../05-常见任务/新增管理台页面.md) 操作
- 路由必须挂五域权限码（见 [权限模型](../02-架构与权限/权限模型.md)）
- locale 参考 `frontend/src/App.vue`（Ant Design Vue zh_CN）
