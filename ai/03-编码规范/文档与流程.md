# 文档与流程规范（强制）

## 活文档（唯一四份 + CHANGELOG）

| 文档 | 何时更新 |
| --- | --- |
| `docs/产品需求.md` | 功能/验收条件变化时 |
| `docs/应用对接.md` | 对接契约变化时 |
| `docs/部署与运维.md` | 部署/运维变化时 |
| `docs/项目启动.md` | 启动方式变化时 |
| `CHANGELOG.md` | **每次**功能、修复、文档或验收工作结束前 |

## CHANGELOG 记录规则

1. 每次工作结束前追加本次**事实记录**
2. 必须含验证结果；没运行的验证明确写 **"未运行"**
3. 范围变化时同步 `docs/产品需求.md` 的验收条件
4. 日常交接**不自动**触发全项目审计，不创建后台自动任务

## 任务与验收纪律

- 保留任务 ID
- 分开记录：源码完成 / 隔离或 mock 验证 / 目标环境验收
- **禁止**仅凭历史测试或局部通过就标记端到端完成

## 文档同步

- 按 IAM Skill（`.codex/skills/iam-project/SKILL.md`）同步根目录与前后端 README、产品需求
- 项目结构变化时同步 `ai/` 本导航（见 `ai/README.md` 维护规则）
