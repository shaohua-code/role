## 27 权限码 · 五域

admin 面板**逐路由**按五域权限码判权：

| 域 | 前缀 | 管什么 |
| --- | --- | --- |
| 平台 | `platform.*` | 平台级设置与全局管理 |
| RBAC | `rbac.*` | 角色、权限码定义 |
| 组织 | `org.*` | 组织与组织工作台 |
| 应用 | `app.*` | 应用与应用工作台 |
| 运维 | `ops.*` | 审计、健康、运维操作 |

- 权威码表：`docs/产品需求.md`（与 `backend/app/services/rbac_guards.py` 保持一致）。
- **业务权限码强制 data_scope**：业务类权限必须携带数据范围约束。
- 前端路由表（`frontend/src/router/`）逐路由挂权限码；后端接口用 `admin_authorization.py` / `rbac_guards.py` 的依赖判权。前后端必须同码。

## 改权限相关代码的必检清单

1. 新增/修改权限码 → 同步 `rbac_guards.py` + `docs/产品需求.md` 权威码表（见 [05-常见任务/新增权限码.md](../05-常见任务/新增权限码.md)）
2. 角色计算 → 只改 `effective_roles.py`，并确认没有旁路实现
3. 接口判权 → 用现成依赖（`admin_authorization.py`），不要手写 `if role == ...`
4. 前端路由 → 路由 meta 挂权限码，与后端同码
