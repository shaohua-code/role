# 前后端调用链

## 管理台请求链路

```
frontend/src/views/**/index.vue          页面
  → frontend/src/api/**                  接口封装（页面禁止裸写 axios）
    → backend/app/api/v1/admin/*.py      路由层（参数校验入口）
      → backend/app/services/*.py        业务逻辑 + 鉴权（admin_authorization / rbac_guards）
        → backend/app/models/*.py        ORM 模型
          → backend/app/db/              会话与连接
响应 ← backend/app/schemas/*.py           Pydantic 出参序列化
```

## 分层纪律

| 层 | 允许做 | 禁止做 |
| --- | --- | --- |
| api 路由层 | 解析请求、调 service、返回 schema | 写业务逻辑、直接操作 db |
| services | 业务逻辑、鉴权、跨模型编排 | 直接返回未序列化 ORM 对象给路由 |
| schemas | 定义出入参 | 夹带业务逻辑 |
| models | 表结构定义 | 业务逻辑 |

## 特殊链路

- **OIDC**：`api/v1/oidc_provider/`（authorization → tokens → logout/metadata），对接契约见 `docs/应用对接.md`
- **租户管理员**：`api/v1/tenant_admin/`（如 application_roles）
- **文件上传**：`api/v1/admin/uploads.py`
- **健康检查**：`api/v1/health.py`

## 前端约定

- 新接口先在 `frontend/src/api/` 对应模块文件中封装，再在页面调用
- 路由（`frontend/src/router/`）逐路由挂五域权限码，与后端同码
- 后端加接口 → 前端同步封装 → 两端权限码一致（见 [05-常见任务/新增后端接口.md](../05-常见任务/新增后端接口.md)）
