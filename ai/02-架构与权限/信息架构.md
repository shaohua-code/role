# 管理台信息架构（IA）

> 权威定义：`docs/产品需求.md` 的 UI 硬规则章节。侧栏实现：`frontend/src/layout/`。

## 侧栏三大块

```
侧栏
├── 应用工作台      ← 应用相关日常操作的主入口
├── 组织工作台      ← 组织相关日常操作的主入口
└── 高级管理        ← 平台角色、权限编码、用户组 等独立列表
```

## 分工规则（易错点）

| 操作 | 在哪做 | 不在哪做 |
| --- | --- | --- |
| 应用目录 CRUD | **应用工作台**（左树新建，节点右侧「更多」打开弹窗） | 不在高级管理 |
| 组织目录 CRUD | **组织工作台**（左树新建，节点「更多」弹窗） | 不在高级管理 |
| 平台角色 / 权限编码 / 用户组 | **高级管理**（独立列表） | 不塞进工作台 |
| 资源树 | **正式能力**，属应用工作台体系 | 不是实验特性 |

## 前端落点

- 工作台页面：`frontend/src/views/application-workspace/`、`frontend/src/views/organization-workspace/`
- 高级管理页面：`frontend/src/views/roles/`、`access-control/`、`groups/` 等
- 归档（禁止恢复）：`frontend/src/views/_archive/`

## 改 IA 的规矩

1. 改侧栏 / 菜单结构 → 必须同步 `docs/产品需求.md` 与本导航
2. 新页面必须先确认归属（工作台 or 高级管理），再决定路由与权限码
3. 遵守 UI 硬规则：通用组件优先、`文件夹/index.vue` 写法、关联文件同文件夹
