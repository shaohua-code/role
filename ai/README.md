# AI 导航（给 AI 的项目入口）

> 本文件夹是写给 AI 看的项目导航地图。目标：让 AI 在动手写代码之前，用最短时间理解项目结构、规范、权限模型和红线。
>
> **权威信息源永远在仓库本体**：`docs/产品需求.md`（产品与验收）、`AGENTS.md`（协作规则）、源码本身。本导航只负责"指路 + 提炼"，与源码冲突时以源码和活文档为准。

## 接手任务的标准阅读路径

1. **必读**：[01-项目概览/项目是什么.md](01-项目概览/项目是什么.md) → 30 秒知道这是什么项目
2. **必读**：[01-项目概览/目录地图.md](01-项目概览/目录地图.md) → 知道代码放在哪
3. **改前后端前必读**：[03-编码规范/](03-编码规范/) → 强制规范，违反会被打回
4. **涉及权限/菜单/路由时必读**：[02-架构与权限/](02-架构与权限/)
5. **改具体功能前**：到 [04-模块导航/](04-模块导航/) 找到对应模块，按指路直接跳到真实代码位置
6. **动手前**：查 [06-红线与门禁/不可破坏的规则.md](06-红线与门禁/不可破坏的规则.md)，确认不会踩线
7. **收尾时**：按 [03-编码规范/文档与流程.md](03-编码规范/文档与流程.md) 更新 CHANGELOG

## 维护规则

- 项目结构变化（新增/移动/删除目录、新增模块）时，**必须同步更新本导航**对应文件。
- 新增业务模块时：在 `04-模块导航/` 下新建模块文件夹 + `导航.md`，并更新上表。
- 本导航内不复制大段产品需求内容，只指路 + 提炼，避免双源失同步。
