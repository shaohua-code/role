# Playbook：新增后端接口

## 步骤

1. **定契约**：明确出入参，在 `backend/app/schemas/` 定义 Pydantic 模型
2. **写业务**：在 `backend/app/services/` 新增或扩展 service（一个文件一个职责）；业务逻辑禁止写在路由层
3. **挂路由**：
   - 管理台接口 → `backend/app/api/v1/admin/<模块>.py`
   - 租户管理员接口 → `backend/app/api/v1/tenant_admin/`
   - 通用工具复用 `api/v1/admin/common.py`
4. **挂鉴权**：使用 `services/admin_authorization.py` / `services/rbac_guards.py` 现成依赖，按菜单/按钮节点码判权；**禁止**手写 `if role == ...`
5. **表结构变更**：走 `backend/migrations/` 迁移；**迁移前必须受保护备份 + 用户明确授权**（红线）
6. **前端同步**：`frontend/src/api/` 封装 + 路由权限码与后端一致（见 [新增管理台页面.md](新增管理台页面.md)）
7. **收尾**：CHANGELOG 记录（验证结果如实写，没跑就写"未运行"）

## 检查清单

- [ ] 业务逻辑只在 services 层
- [ ] 鉴权用现成依赖，权限码在权威码表中（或已同步码表）
- [ ] 涉及审计落库 → 过 `access_log_redaction.py` 脱敏
- [ ] 涉及登录 → 保留 `login_throttle.py` 限流
- [ ] Ruff 通过；相关测试运行（或注明未运行）
