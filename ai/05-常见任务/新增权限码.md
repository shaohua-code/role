# Playbook：新增权限码

> 权限码是全系统安全基线，改动必须双源同步，缺一不可。

## 权威双源

1. `docs/产品需求.md` 的权威码表（27 码：`platform.*` / `rbac.*` / `org.*` / `app.*` / `ops.*`）
2. `backend/app/services/rbac_guards.py`（判权守卫）

## 步骤

1. **确认必要性**：能否用现有码覆盖？能用就不新增
2. **确定归属域**：五域之一；业务权限码必须带 data_scope
3. **后端**：`rbac_guards.py` 注册新码
4. **文档**：`docs/产品需求.md` 权威码表同步
5. **前端**：用到该码的路由 meta 挂码（`frontend/src/router/`）
6. **角色开通**：需要挂到哪些角色 → `services/role_provisioning.py` / `effective_roles.py` 路径确认
7. **收尾**：CHANGELOG 记录 + 验证结果

## 禁止

- 禁止复活已作废码：`iam.*`、`platform.super_admin`、`tenant.org_admin`
- 禁止只在后端或只在文档单边添加
- 禁止在 `effective_roles.py` 之外实现角色 → 码的映射
