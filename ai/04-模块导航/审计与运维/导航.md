# 审计与运维 模块导航

## 模块定位

审计日志、总览看板、日志脱敏、维护模式、权限健康、模型用量入口（用量细节见「模型用量」模块）。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/audit/` | 审计日志 |
| 前端页面 | `frontend/src/views/overview/` | 总览看板 |
| 后端路由 | `backend/app/api/v1/admin/audit.py` | 审计接口 |
| 后端路由 | `backend/app/api/v1/admin/overview.py` | 总览接口 |
| 后端服务 | `backend/app/services/access_log_redaction.py` | 日志脱敏（落库必过） |
| 后端服务 | `backend/app/services/maintenance.py` | 维护模式 |
| 后端服务 | `backend/app/services/public_registration.py` | 公开注册开关（门禁管控） |

## 注意事项

- 运维权限码属 `ops.*` 域
- 任何写审计的代码必须先过 `access_log_redaction.py` 脱敏，禁止明文落敏感字段
- 权限健康页面（`views/permission-health/`）与 `services/permission_impact.py` 关联
