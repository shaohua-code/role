# 用户与用户组 模块导航

## 模块定位

用户管理、用户组（独立列表进高级管理）、成员邀请。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/users/` | 用户管理 |
| 前端页面 | `frontend/src/views/groups/` | 用户组（高级管理） |
| 前端页面 | `frontend/src/views/invitations/` | 邀请 |
| 后端路由 | `backend/app/api/v1/admin/users.py` | 用户接口 |
| 后端路由 | `backend/app/api/v1/admin/groups.py` | 用户组接口 |
| 后端路由 | `backend/app/api/v1/admin/invitations.py` | 邀请接口 |

## 注意事项

- 用户组在侧栏 IA 中归「高级管理」，不进工作台
- 用户角色授予走 `services/effective_roles.py` / `role_provisioning.py`，不要手写角色判断
- 邀请流程涉及 `services/email.py`
