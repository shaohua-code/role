# 角色与访问控制 模块导航

## 模块定位

五级平台角色、应用角色、权限码定义与判权、访问控制管理、权限健康检查。**整个系统权限模型的核心模块。**

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/roles/` | 角色管理（高级管理） |
| 前端页面 | `frontend/src/views/access-control/` | 访问控制 |
| 前端页面 | `frontend/src/views/permission-health/` | 权限健康 |
| 后端路由 | `backend/app/api/v1/admin/access_control.py` | 访问控制接口 |
| 后端路由 | `backend/app/api/v1/authorization.py` | 授权接口 |
| 后端服务 | `backend/app/services/effective_roles.py` | **唯一有效角色实现**（五级角色） |
| 后端服务 | `backend/app/services/rbac_guards.py` | **菜单/按钮节点判权守卫** |
| 后端服务 | `backend/app/services/admin_authorization.py` | 管理台鉴权依赖 |
| 后端服务 | `backend/app/services/permission_namespace.py` | 权限码命名空间 |
| 后端服务 | `backend/app/services/permission_kinds.py` | 权限码种类 |
| 后端服务 | `backend/app/services/permission_impact.py` | 权限影响分析 |
| 后端服务 | `backend/app/services/role_provisioning.py` | 角色开通 |

## 注意事项

- 改本模块 = 改权限模型，务必先读 [02-架构与权限/权限模型.md](../../02-架构与权限/权限模型.md)
- 权限码属 `rbac.*` 域；新增权限码走 [05-常见任务/新增权限码.md](../../05-常见任务/新增权限码.md)
- 业务权限码强制 data_scope
- 已作废概念禁止复活：`iam.*`、`platform.super_admin`、`tenant.org_admin`
