# 组织管理 模块导航

## 模块定位

组织（organization）目录树与组织工作台。组织 CRUD 一律在组织工作台完成。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/organization-workspace/` | **组织工作台**（组织 CRUD 主入口） |
| 后端路由 | `backend/app/api/v1/admin/organizations.py` | 组织管理接口 |

## 注意事项

- IA 规则：组织目录 CRUD 在工作台做（左树新建，节点右侧「更多」打开弹窗），**不放高级管理**
- 组织权限码属 `org.*` 域
- 组织相关 UI 改动遵守 `docs/产品需求.md` 的 UI 硬规则（通用组件优先、`文件夹/index.vue`）
