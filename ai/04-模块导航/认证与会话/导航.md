# 认证与会话 模块导航

## 模块定位

登录认证、会话管理、OIDC Provider（业务应用单点登录）、登出、登录限流、邮件验证码/通知。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/auth/` | 登录等页面 |
| 前端页面 | `frontend/src/views/profile/` | 个人中心 |
| 前端 API 封装 | `frontend/src/api/` | auth 相关封装 |
| 后端路由 | `backend/app/api/v1/auth.py` | 登录/登出/会话接口 |
| 后端路由 | `backend/app/api/v1/oidc_provider/` | OIDC：authorization、tokens、logout、metadata |
| 后端服务 | `backend/app/services/login_throttle.py` | 登录限流（不可绕过） |
| 后端服务 | `backend/app/services/backchannel_logout.py` | 后通道登出 |
| 后端服务 | `backend/app/services/email.py` | 邮件发送 |
| 后端服务 | `backend/app/services/public_registration.py` | 公开注册（有上线门禁） |

## 注意事项

- `ALLOW_BOOTSTRAP_EMAIL_BYPASS` 生产必须 `false`
- 公开注册属于上线门禁管控能力，改动需确认门禁状态
- OIDC 对接契约见 `docs/应用对接.md`
- 认证流程必须包含邮箱验证（用户约束）
