# 模型分发与用量 模块导航

## 模块定位

模型三级分发（平台 → 租户 → 应用）与模型用量（model usage）统计。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/models/` | 模型治理页（平台目录 + 下发租户弹窗） |
| 前端页面 | `frontend/src/views/application-workspace/tabs/ModelsTab.vue` | 应用工作台「模型」Tab（租户收到的清单 + 下发/回收应用） |
| 后端路由 | `backend/app/api/v1/admin/models.py` | 平台目录 + tenant-grants 下发管理 |
| 后端路由 | `backend/app/api/v1/tenant_admin/application_models.py` | 工作台模型 Tab 三端点 |
| 后端路由 | `backend/app/api/v1/admin/model_usage.py` | 管理台用量接口 |
| 后端路由 | `backend/app/api/v1/model_usage.py` | 网关用量/预留（按三级下发校验） |
| 后端路由 | `backend/app/api/v1/authorization.py` | `GET /authorization/my-models`（三级交集契约） |
| 后端服务 | `backend/app/services/model_distribution.py` | ModelDistribution：下发/回收软失效、级联、可见性解析（唯一口径） |

## 注意事项

- 用量数据涉及统计口径，改动前先确认现有聚合逻辑
- 管理台展示走 `admin/model_usage.py`，非管理端走 `api/v1/model_usage.py`，不要混用
- 三级可见性唯一口径（产品需求 §6.4）：应用可见 = 平台目录 ∩ 租户下发 ∩ 应用下发；`ModelCatalog` 行统一归属 platform 租户，可见性/记账校验一律走 `ModelDistribution`，禁止再按 `model_catalog.tenant_id` 匹配消费租户；按 ID 的目录 / 下发操作强制校验平台租户归属（非平台行 404）
- `my-models` 清单范围绑定服务端验签的 OIDC 应用身份（`client_id` 仅作一致性校验，不一致 403；管理会话不可调用）；`model.invoke` 判权按三级下发关系（evaluate_access 特例分支，不走角色授权/数据范围）
- 目录写 = 超管 `button.models.manage`；下发/回收应用 = `button.models.distribute`（min_scope=tenant，L2 只读）；回收为软失效（revoked 行保留），租户级回收级联失效其应用下发；迁移 head `0009_model_distribution`
