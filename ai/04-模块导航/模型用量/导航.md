# 模型分发与用量 模块导航

## 模块定位

模型三级分发（平台 → 租户 → 应用）与模型用量（model usage）统计。

后续模型连通性与对话调试页面方案见 [`docs/模型测试台设计.md`](../../../docs/模型测试台设计.md)；可交互原型见 [`docs/prototypes/模型测试台-交互式原型.html`](../../../docs/prototypes/模型测试台-交互式原型.html)（数据为模拟）。

## 模型测试台（2026-11-18 实施：判定 + 受控通道）

- 前端页面：`frontend/src/views/models/test/`（index + components：ContextBar / StatusStrip / ChatColumn / DiagnosticPanel / DebugDrawer，api.ts 含 SSE fetch 流消费）；路由 `/models/test?model_id=...`，PageKey `model_test`，不占侧栏，入口在模型治理目录行操作「测试」，可达性与模型治理同码 `menu.models`，页内动作另按 `button.models.manage` 收口
- 后端：`backend/app/api/v1/admin/model_tests.py` → test-context 判定 / test-connection 探针（凭据→网络TLS→GET /models，不产生计费 token）/ test-conversations 会话 + events SSE（单调 sequence，last_sequence 重连去重）+ cancel；外呼前逐请求重验三级下发交集（403 authz_denied）
- 受控出口：`backend/app/services/model_channel.py`（OpenAI 兼容流式）；凭据引用仅支持 `secret://env/<变量名>`（环境变量注入，`vault://` 未接入返回明确分类错误）；endpoint_url 优先，`_PROVIDER_DEFAULT_BASE_URLS` 内置 deepseek/openai/moonshot/qwen(dashscope)/zhipu(glm)/yasoll/openrouter/siliconflow 默认端点，未列入的必须显式配置；错误统一稳定分类（credential_unavailable / credential_rejected / rate_limited+Retry-After / connect_timeout / read_timeout / network_error / upstream_error），不透传上游正文
- 供应商密钥注入（2026-11-19 简化）：compose.yaml api 服务以 `env_file: - ./.env` 整文件注入根 `.env`（显式 environment 仍优先）；新增供应商**只改 `.env`** 追加 `XXX_API_KEY=<真实密钥>` + `docker compose up -d api` 重建，无需改 compose.yaml；管理台表单凭证只填环境变量名（前端组装 secret://env/ 引用，编辑态回显变量名），明文密钥不入库不回读
- 用量账目：后台任务落 `ModelUsageEvent(source='model_test')`（迁移 **0010_model_test_usage_source** 放宽 CHECK——**执行 `alembic upgrade head` 前须按门禁完成受保护备份并取得授权**；未迁移前对话可用但落账会失败）；Provider 返回精确用量则用之，否则按字符估算并标 usage_is_estimated（未知≠0）
- 会话仅存进程内存（正文/思考不落库不进日志），TTL 自动回收；审计只记操作者/模型/动作/结果/请求 ID/时间
- 多轮上下文：前端仅送最近 10 个已完成轮次（最多 32000 字），后端 `TestConversationCreate` 校验完整 user/assistant 交替、大小和字段白名单；编辑重发截断后续，切换目标取消在途调用。调试参数目前仅温度、Top P、输出上限和系统提示词生效
- 单测：`tests/test_model_test_context.py`（IsolatedAsyncioTestCase，StaticPool 跨线程）、`tests/test_model_channel.py`（MockTransport：SSE 解析/错误分类/取消/凭据）、`tests/test_model_test_history.py`（多轮顺序/边界/字段白名单）

## 注意事项

- 用量数据涉及统计口径，改动前先确认现有聚合逻辑
- 管理台展示走 `admin/model_usage.py`，非管理端走 `api/v1/model_usage.py`，不要混用
- 三级可见性唯一口径（产品需求 §6.4）：应用可见 = 平台目录 ∩ 租户下发 ∩ 应用下发；`ModelCatalog` 行统一归属 platform 租户，可见性/记账校验一律走 `ModelDistribution`，禁止再按 `model_catalog.tenant_id` 匹配消费租户；按 ID 的目录 / 下发操作强制校验平台租户归属（非平台行 404）
- `my-models` 清单范围绑定服务端验签的 OIDC 应用身份（`client_id` 仅作一致性校验，不一致 403；管理会话不可调用）；`model.invoke` 判权按三级下发关系（evaluate_access 特例分支，不走角色授权/数据范围）
- 目录写 = 超管 `button.models.manage`；下发/回收应用 = `button.models.distribute`（min_scope=tenant，L2 只读）；回收为软失效（revoked 行保留），租户级回收级联失效其应用下发；迁移 head `0009_model_distribution`
