# 应用与应用工作台 模块导航

## 模块定位

应用（application）注册、应用目录树、资源树（正式能力）、应用工作台。

## 代码入口

| 端 | 路径 | 说明 |
| --- | --- | --- |
| 前端页面 | `frontend/src/views/applications/` | 应用相关页面 |
| 前端页面 | `frontend/src/views/application-workspace/` | **应用工作台**（应用目录 CRUD 主入口；右 Tab = 角色/权限编码/资源权限/模型） |
| 后端路由 | `backend/app/api/v1/admin/applications.py` | 应用管理接口 |
| 后端路由 | `backend/app/api/v1/admin/application_resources.py` | 资源树接口 |
| 后端路由 | `backend/app/api/v1/tenant_admin/application_models.py` | 工作台「模型」Tab（三级分发第三级，详见 模型用量 导航） |

## 注意事项

- IA 规则：应用目录 CRUD 在工作台做（左树新建，节点「更多」弹窗），**不放高级管理**
- 资源树是**正式能力**，不是实验特性
- 应用权限码属 `app.*` 域
- 应用角色可挂：租户/应用管理码（操作者可见）+ 本应用业务码（业务码强制 data_scope）
- 「模型」Tab：展示本租户收到的平台模型；写操作认 `button.models.distribute`（L3 可写、L2 只读），分发口径见 `services/model_distribution.py`
- 业务应用对接（SDK/Sideband）见 `docs/应用对接.md` 与 `sdk/`；本阶段不做 DeerFlow 接入
