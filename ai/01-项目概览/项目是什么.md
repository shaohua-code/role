# 项目是什么

## 一句话定位

**IAM（身份与访问管理）平台**：一个管理台前端 + 一个绿场（greenfield，从零重建）后端，负责租户、组织、应用、角色、用户、权限码、审计的统一管理。

## 技术栈

| 端 | 技术 |
| --- | --- |
| 前端 `frontend/` | Vue 3（`<script setup>` 组合式 API）+ Vite + TailwindCSS v3 + Ant Design Vue（组件库 locale 参考 `frontend/src/App.vue` 的 zh_CN 用法） |
| 后端 `backend/` | Python + FastAPI 风格分层（api / services / schemas / models / db），Ruff 做 lint（见 `backend/.ruff_cache`） |
| 编排 | Docker Compose：`compose.yaml`（本地）、`compose.production.yaml`（生产） |
| 数据库迁移 | `backend/migrations/` |

## 本阶段范围（重要）

- **只维护**：IAM 管理台前端 + 绿场后端。
- **不做**：DeerFlow / 业务项目接入联调。旧「新项目接入」视图已归档到 `frontend/src/views/_archive/integration/`，不要恢复。
- 权限模型以方案 A 绿场重建规格为准；产品分层与验收条件以 `docs/产品需求.md` 为准。

## 运行形态

- 本地启动：`start-local.ps1`；本地验证：`verify-local.ps1`（详见 [05-常见任务/本地启动与验证.md](../05-常见任务/本地启动与验证.md)）。
- 生产部署与运维：见 `docs/部署与运维.md`。
- 环境变量：根目录 `.env`（本地）、`.env.compose.example`、`.env.production.example`（示例模板，真实 `.env` 不入库）。
