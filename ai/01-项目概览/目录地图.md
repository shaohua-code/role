# 目录地图

## 根目录

| 路径 | 作用 | AI 注意事项 |
| --- | --- | --- |
| `frontend/` | 管理台前端（Vue3 + Vite + Tailwind） | 改前端主要在这里 |
| `backend/` | 绿场后端（FastAPI 风格） | 改后端主要在这里 |
| `docs/` | 四份活文档：产品需求 / 应用对接 / 部署与运维 / 项目启动 | 唯一权威文档，改功能要同步验收条件 |
| `deploy/` | 部署相关物料 | 部署改动先读 `docs/部署与运维.md` |
| `scripts/` | 运维 / 辅助脚本 | |
| `sdk/` | 对外 SDK（业务应用对接用） | 契约见 `docs/应用对接.md` |
| `backups/` | 受保护备份 | 迁移类操作需备份 + 明确授权 |
| `.codex/skills/iam-project/SKILL.md` | 项目开发技能说明 | 项目开发遵循此 Skill |
| `ai/` | 本导航文件夹 | |
| `AGENTS.md` | 仓库协作规则 | 每次接手先读 |
| `CHANGELOG.md` | 历史事实记录 | 每次工作结束前追加记录 |
| `compose*.yaml` | 本地 / 生产 / 密钥轮换编排 | |
| `start-local.ps1` / `verify-local.ps1` | 本地启动 / 验证脚本 | |
| `.env*` | 环境变量（`.env` 不入库） | 不要提交真实密钥 |

## frontend/src 结构

| 目录 | 作用 |
| --- | --- |
| `views/` | 页面，按模块分文件夹，**必须用 `文件夹/index.vue` 写法** |
| `components/` | 通用组件（有现成组件必须先用，禁止重复造轮子） |
| `api/` | 接口封装层，页面不直接写 axios |
| `composables/` | 组合式函数 |
| `layout/` | 布局与侧栏（信息架构入口） |
| `router/` | 路由表，逐路由挂权限码 |
| `plugins/` | 插件注册（如 Ant Design Vue） |
| `styles/` | 全局样式（项目要求 100% Tailwind 工具类） |
| `utils/` | 工具函数 |
| `views/_archive/` | 已归档视图（如 integration/），**不要恢复、不要引用** |

### views 模块清单

`overview`（总览）、`auth`（登录）、`profile`（个人）、`tenants`（租户）、`tenant-admin`（租户管理员）、`organizations`（组织）、`organization-workspace`（组织工作台）、`applications`（应用）、`application-workspace`（应用工作台）、`roles`（角色）、`access-control`（访问控制）、`groups`（用户组）、`users`（用户）、`invitations`（邀请）、`audit`（审计）、`permission-health`（权限健康）、`themes`（主题）、`models`（模型）、`integration-guide`（接入指南）

## backend/app 结构

| 目录 | 作用 |
| --- | --- |
| `api/v1/` | 路由层：`auth.py`、`authorization.py`、`health.py`、`model_usage.py` |
| `api/v1/admin/` | 管理台接口：access_control、applications、application_resources、audit、common、groups、invitations、models、model_usage、organizations、overview、tenants、themes、uploads、users |
| `api/v1/tenant_admin/` | 租户管理员接口（application_roles 等） |
| `api/v1/oidc_provider/` | OIDC Provider：authorization、tokens、logout、metadata 等 |
| `services/` | 业务逻辑（鉴权核心在这里） |
| `schemas/` | Pydantic 请求/响应模型 |
| `models/` | ORM 模型 |
| `db/` | 数据库连接与会话 |
| `core/` | 配置、安全等核心设施 |

### services/ 关键文件（权限模型权威实现）

| 文件 | 职责 |
| --- | --- |
| `effective_roles.py` | **唯一有效角色实现**（五级平台角色计算） |
| `rbac_guards.py` | **27 权限码判权守卫**（权威码表镜像） |
| `admin_authorization.py` | 管理台接口鉴权依赖 |
| `authorization.py` | 通用授权 |
| `permission_namespace.py` / `permission_kinds.py` / `permission_impact.py` | 权限码命名空间 / 种类 / 影响分析 |
| `role_provisioning.py` | 角色开通 |
| `login_throttle.py` / `backchannel_logout.py` / `email.py` | 登录限流 / 后通道登出 / 邮件 |
| `access_log_redaction.py` | 审计日志脱敏 |
| `maintenance.py` / `public_registration.py` / `theme_config.py` | 维护模式 / 公开注册 / 主题配置 |
