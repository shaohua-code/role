# 12 — UI 设计系统验收清单（一页）

对照 [12-ui-design-system.md](./12-ui-design-system.md)。每项 □ → 通过打 ☑。

## A. Token 与工程

- [ ] 存在唯一色板源（`styles/tokens.css` 或等价），业务文件无新增裸 hex
- [ ] Ant `ConfigProvider` theme 从 token/bridge 生成，而非散落魔法字符串
- [ ] 品牌色变更只改一处，侧栏/按钮/focus/表格 hover 联动
- [ ] Tailwind 间距仅为 4 的倍数（无 `p-[13px]` 等）
- [ ] `shared/theme.ts` 未承担管理台色板职责（仅登录主题工具）

## B. 气质与主题

- [ ] 管理台无大面积流动光斑 / 彩虹渐变堆砌
- [ ] 深色侧栏为克制纯色（或极弱纹理），选中为中性底 + 品牌指示条
- [ ] 内容区浅色默认；暗色模式正文对比度可读
- [ ] 主色占用面积克制（非处处紫色）

## C. 布局

- [ ] 侧栏宽 240 / 折叠 72；顶栏高 56
- [ ] 内容区 max-width 1440 居中；水平 padding 符合规范
- [ ] 新列表页使用统一 PageHeader + 主卡片表格模板
- [ ] 无「业务页自建第二套 Sider」

## D. 组件

- [ ] 每页 Primary 按钮 ≤ 1
- [ ] 危险操作有确认
- [ ] 表格：空态 / loading / 操作列收敛
- [ ] 表单：标签完整、校验文案可读、提交 loading
- [ ] Modal/Drawer 关闭后状态重置

## E. 导航

- [ ] 图标同套、同粗细
- [ ] 选中/hover/分组样式符合规范
- [ ] 与权限裁剪后的菜单一致（无空白无权限项）

## F. 动效与 a11y

- [ ] 动效 ≤ 200ms；尊重 `prefers-reduced-motion`
- [ ] Focus ring 可见
- [ ] 禁用/空/错状态齐全
- [ ] 正文对比度基本达标

## G. 走查页面（抽样）

- [ ] 登录页
- [ ] 工作台 / 租户列表 / 应用列表
- [ ] 用户或组织表格页
- [ ] 角色权限编辑 / 授权模拟
- [ ] 审计或模型用量
- [ ] 窄屏 <650px 侧栏抽屉可用
