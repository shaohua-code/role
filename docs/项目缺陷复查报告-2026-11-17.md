## P1-1 `my-resources` 未绑定已验证的 OIDC 应用

**位置：** `backend/app/api/v1/authorization.py:100`–`148`；对照同文件 `list_my_models()` 的应用身份校验（约 55–72 行）和 `backend/app/core/security.py:244`–`245`。

**证据：** `list_my_resources()` 直接以调用方传入的 `client_id` 查找应用，只验证用户在目标应用所属租户有活动成员关系，再按该应用查有效角色与资源授权；未要求 `_auth_protocol == "oidc"`，也未比较已验签的 `_oidc_application_id`。`current_user()` 已提供这些服务端可信字段，`my-models` 已使用它们。现有 `backend/tests/test_application_resources.py` 只覆盖本应用资源、组继承、停用和未知 client，缺同租户跨应用与管理令牌边界用例。

**影响：** 一个用户同时能进入应用 A、B 时，持 A 的 OIDC access token 把 `client_id` 改成 B，就可能读取 B 的菜单、按钮、路径、描述及 `extra`。管理 access token 也可按任意已绑定应用的 `client_id` 请求该业务资源树。资源树是正式下发能力，此行为与“本应用资源”契约和已修复的 `my-models` 边界不一致。

**修复目标：** 业务消费端只接受 OIDC 应用令牌，以服务端验签的应用 ID 决定资源范围；`client_id` 仅做一致性校验。对跨应用、管理令牌、停用租户/应用和本应用正常路径增加 handler 与 HTTP 层回归。无权响应不得包含目标应用资源字段。

## P1-2 密码授权端点缺少登录失败节流

**位置：** `backend/app/api/v1/oidc_provider/tokens.py:206`–`234`；对照管理登录 `backend/app/api/v1/auth.py:409`–`426` 和 `backend/app/services/login_throttle.py`。

**证据：** `grant_type=password` 对 trusted 客户端直接按邮箱查用户并执行密码哈希校验；失败返回 `invalid_grant`，没有调用 `LoginThrottleService.begin_login_attempt()` / `record_login_failure()` / 成功清理，也没有失败审计。`backend/tests/test_oidc_consent.py` 仅覆盖一次错误密码，不覆盖连续失败、锁定或来源 IP。管理登录已有三桶限流实现，但此入口未复用。

**影响：** 一旦 trusted 客户端凭据泄露或被滥用，攻击者可绕过管理登录的账号 / 来源节流，对公开可达的 token 端点持续尝试密码，并反复消耗密码哈希计算资源。trusted 标记只限制客户端身份，不能代替用户密码的失败节流。

**修复目标：** 在密码授权分支复用统一的可信客户端 IP 解析和三桶节流，在数据库事务中记录失败 / 清理成功；保留 OAuth 统一错误语义，同时给被限流请求合理的 HTTP 状态和 `Retry-After`。覆盖同账号跨 IP、同来源多账号、并发失败、成功重置和代理地址缺失场景；确认不会影响授权码与 refresh grant。

## P2 审计页“管理操作”包含认证事件

**位置：** `frontend/src/views/audit/AuditLogPage.vue:52`–`77`、`:179`–`182`；服务端 `backend/app/api/v1/admin/audit.py:60`–`67`。

**证据：** 页面文案和筛选选项把“登录与认证”定义为 `auth.*`，“管理操作”定义为非 `auth.*`；但请求只在认证 Tab 加 `action_prefix=auth.`，管理 Tab 不加排除条件，因此查的是全量审计记录。分页总数也包含 `auth.*`。这与两类分开浏览的设计不一致。

**影响：** 管理操作列表和计数混入登录、刷新、密码重置等事件；认证事件量大时会挤掉真正的管理操作，筛选结果易误读。若产品本意是“全部操作”，应修改 Tab 命名与筛选定义；否则服务端需要提供可分页的排除条件。

**修复目标：** 给审计查询增加明确类别过滤，并在数据库查询与 count 中同源应用；管理 Tab 排除认证类，认证 Tab 仅含认证类。覆盖两类分页计数和切换 Tab 的回归。
