# 项目启动

面向本仓库本地开发环境的最短启动路径。备份、迁移门禁和生产发布见 [部署与运维](部署与运维.md)。产品规则见 [产品需求](产品需求.md)。

## 1. 前置检查

在 PowerShell 中进入仓库根目录，确认 Docker Desktop 已启动、Engine Running、Compose v2 可用。先定位实际 CLI，避免 Windows 的 `docker` 别名遮蔽 Docker Desktop：

```powershell
Set-Location -LiteralPath 'D:\project\role'
$iamDocker = Get-Command docker.exe -CommandType Application -All -ErrorAction SilentlyContinue |
  Where-Object { $_.Source -and (Test-Path -LiteralPath $_.Source -PathType Leaf) } |
  Select-Object -First 1 -ExpandProperty Source
if (-not $iamDocker) {
  $iamDocker = Get-Process docker -ErrorAction SilentlyContinue |
    Where-Object { $_.Path -and (Test-Path -LiteralPath $_.Path -PathType Leaf) } |
    Select-Object -First 1 -ExpandProperty Path
}
if (-not $iamDocker) { throw '未找到 Docker CLI，请先修复 Docker Desktop 或 PATH' }
& $iamDocker compose version
if ($LASTEXITCODE -ne 0) { throw 'Docker Compose v2 不可用' }
& $iamDocker info --format '{{.ServerVersion}}'
if ($LASTEXITCODE -ne 0) { throw 'Docker Engine 未就绪' }
```

找不到 CLI 或无法连接 Engine 时，先处理 Docker Desktop，不要猜测安装目录。

## 2. 首次配置

仅当根目录没有 `.env` 时创建（**禁止覆盖**已有运行配置）：

```powershell
if (-not (Test-Path -LiteralPath '.env' -PathType Leaf)) {
  Copy-Item -LiteralPath '.env.compose.example' -Destination '.env'
}
notepad .env
```

- `IAM_JWT_SECRET` 和使用时的 `IAM_MODEL_USAGE_API_KEY` 至少 32 字符；管理员密码至少 16 字符；数据库密码用 URL-safe 随机串。
- `.env` 不提交、不贴聊天。

## 3. 启动

```powershell
.\start-local.ps1 -DockerPath $iamDocker
```

脚本会构建并启动 PostgreSQL / API / 管理台；**不迁移、不创建管理员**。

## 4. 就绪探测

```powershell
Invoke-WebRequest 'http://127.0.0.1:8002/api/v1/ready' -NoProxy -SkipHttpErrorCheck -TimeoutSec 5
& $iamDocker compose exec -T api alembic current
& $iamDocker compose exec -T api alembic heads
```

`health` 200 只证明 API 进程；`ready` 200 才可提交登录。若返回 503 `database_migration_pending`，先确认 `current` 落后于 `heads`，**停下来**按 [部署与运维](部署与运维.md) 走备份、隔离恢复演练和明确授权后再迁移。数据库连接或凭据错误时先排查，不要直接迁移。

全新空库且尚无平台管理员时，迁移成功后经本次初始化授权再运行 bootstrap；修改引导环境变量不会重置既有账号密码。

## 5. 访问入口

| 服务 | 地址 |
|---|---|
| 管理台 | `http://localhost:5175/` |
| API readiness | `http://localhost:8002/api/v1/ready` |
| 本地 API 文档 | `http://localhost:8002/docs` |

端口冲突时在 `.env` 调整 `IAM_CONSOLE_PORT` / `IAM_API_PORT`。

## 6. 日常命令

```powershell
& $iamDocker compose up -d
& $iamDocker compose ps
& $iamDocker compose logs -f api
& $iamDocker compose down
```

- 停止只用 `down`；**禁止 `down -v`**（会删除数据库与签名密钥卷）。
- 隔离验证（随机测试库，不动开发主库）：

```powershell
.\verify-local.ps1 -DockerPath $iamDocker
```

## 7. 可选：SMTP

在根 `.env` 按 `.env.compose.example` 填写 `IAM_SMTP_*`（163 使用 SMTP 授权码，不是登录密码）。`IAM_CONSOLE_PUBLIC_URL` 须与浏览器访问管理台地址一致。改完后：

```powershell
& $iamDocker compose up -d --force-recreate api
```

未配置 SMTP 时忘记密码接口返回 503。成员邀请自动发信另需 `IAM_INVITATION_EMAIL_ENABLED=true`（默认关闭）。公开注册保持关闭，不要为了本地方便打开生产总闸。
